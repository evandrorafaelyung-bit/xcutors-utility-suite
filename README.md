## 🛠️ Troubleshooting Common Issues

- **Injection Fails Immediately**: This usually indicates that the Roblox client version is not fully supported. Check the `Compatibility` tab for the latest supported build and use the `Update Checker` feature.
- **Script Throws Nil Errors**: Ensure that your script is referencing global variables that exist in the target environment. Use the `Remote Debugger` to inspect the global table.
- **UI Does Not Load**: Disable any conflicting screen overlay software and ensure you are running the hub as an administrator (if required by your OS).
